# SecurityWatch（セキュリティ・ウォッチ）

**Windows PC の「勝手な変化」に、気づくための、無料の見守りツール**です。
変化があったときだけ、**あなた自身の Discord** に、通知します。

> ⚠️ これは、**セキュリティソフトの代わりではありません**。
> **入られるのを防ぐものではなく、変化に「気づく」ための道具**です。
> 「これを入れれば安全」という保証は、ありません。

---

## どんなときに役に立つか
VPS（FX 自動売買用のサーバー）や、PC を、遠隔で使っている方が、
「知らないうちに、何かを入れられていないか」に、早く気づくための道具です。

## 見るもの（5分おき）

### ① PC の変化（管理者権限なしで動く部分）
| 見るもの | 気づけること |
|---|---|
| 自動で起動するソフト（Run キー、スタートアップ） | 知らないソフトが、起動のたびに動くようになった |
| 予約タスク（Microsoft 以外） | 知らない予約が、増えた |
| サービス（Windows 標準の場所以外） | 知らないサービスが、増えた |
| ユーザーの一覧、管理者グループ | 新しいユーザーができた、誰かが管理者になった |
| 待ち受けポート（外から接続を待つ入口） | 新しい入口が、開いた |
| リモート操作ソフト（AnyDesk、TeamViewer など） | 新しく現れた |
| リモートデスクトップの接続中の状態 | いま、外から画面が操作されている |
| Windows Defender | 保護が OFF になった、ウイルス定義が3日以上古い |

### ② ログインの記録（管理者権限で動く部分）
| 見るもの | 気づけること |
|---|---|
| 外からのログイン成功（ネットワーク、リモートデスクトップ） | 誰かが外から入った（時刻・ユーザー・接続元） |
| ログイン失敗の連続（同じ接続元から3回以上） | パスワードを、総当たりで試されている |
| 新しいユーザー、パスワードのリセット、グループへの追加 | アカウントを、勝手に作られた、変えられた |
| 新しいサービスの登録 | 知らないサービスが、入った |

毎日1回、「動いています」と届きます。**これが届かなくなったら、止まっています。**

## 見られないもの
- ファイルやブラウザの中身の、持ち出し
- EA やソフトの中の動き、取引の内容
- 変化が起きた「瞬間」（最大5分遅れで気づきます）

## プライバシー（安心のために）
- 通知は、**あなた自身の Discord の Webhook** にだけ、送られます。
- **作者には、何も送られません。** インターネットへの通信は、Discord への通知だけです。
- 通知に、**パスワードやキーは、含まれません**（時刻、ユーザー名、接続元 IP、項目名だけです）。
- すべて、PC の中の**文字のファイル（PowerShell のスクリプト）**です。**中身を、自分で読んで確認できます。**

## インストール方法

1. ZIP を**ダウンロードして、展開**する（右クリック →「すべて展開」）。
2. Discord で、通知を受ける**チャンネルの Webhook** を作り、URL をコピーする。
   （チャンネルの設定 →「連携」→「ウェブフック」→「新しいウェブフック」→「ウェブフックURLをコピー」）
3. 展開したフォルダの **`SecurityWatch.cmd` をダブルクリック**する。
4. 「この変更を許可しますか？」と出たら、**「はい」**。
5. 「SecurityWatch です」という画面で、**「はい」**（インストール）を選ぶ。
6. 説明の画面で、**「はい」**。
7. Webhook の URL を貼り付けて、「OK」。
8. 1〜2分後に、Discord に「開始しました」と届けば、完了です。

### インストールで変更されるもの
- `C:\ProgramData\SecurityWatch\` に、プログラムと記録を置きます。
- 予約タスクを2つ登録します（`SecurityWatch`、`SecurityWatchLogon`）。
- Windows の設定を変えます：
  - セキュリティの記録（ログ）の大きさを、**256MB**にする（約2週間分、残ります）。
  - ログインの成功・失敗、アカウントの作成などを、記録する設定を ON にする。

## 削除方法
もう一度、**`SecurityWatch.cmd` をダブルクリック**して、**「いいえ」**（削除）を選んでください。予約タスクと、フォルダが、削除されます。
（Windows の「ログの大きさ」などの設定は、そのままです。残っていても、問題ありません。）

## ファイルは4つだけ
| ファイル | 役割 |
|---|---|
| `SecurityWatch.cmd` | ダブルクリックする入口（管理者の許可を、1回求めます） |
| `SecurityWatch.ps1` | 本体。**これ1つに、すべての処理が入っています**（読めば、何をしているか分かります） |
| `README.md` | この説明書 |
| `LICENSE` | ライセンス |

## 動作条件
- Windows 10 / 11（PowerShell 5.1 が入っている、標準の状態）
- 普段使っているアカウントが、**管理者**であること
- Discord のアカウント（通知を受けたい場合）

## うまくいかないとき
- 通知が届かない：`C:\ProgramData\SecurityWatch\alerts.log` を、メモ帳で開いてください。記録が残っています。Webhook は、同じフォルダの `webhook.txt` に、URL を1行だけ保存すると、設定できます。
- ウイルス対策ソフトに、警告された：このツールは、予約タスクの登録や、Windows の設定の変更をするため、警告されることがあります。スクリプトの中身は、すべて読めます。不安なときは、インストールしないでください。
